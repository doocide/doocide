# Security

Doocide has no server, so most risks live in the browser: hostile share links or files, private notes leaking into shares, and anything that makes the page load or send data elsewhere.

If you find a problem like that, please report it privately: open the Security tab of this repository and choose **Report a vulnerability**. Please don't open a public issue for it.

Helpful details: what you opened (a link, a file, a template), what happened, and the browser you used. Never include anyone's real decisions or personal data in a report.
